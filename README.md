# Iryna Zinko: resume

Static resume page (HTML, CSS, vanilla JS). No build step.

Run locally:

    python3 -m http.server 8000

Published with GitHub Pages from the `main` branch, root folder.

Updating the commits chart: edit `commits.json` (one `["label", count]` pair per month, newest last), then commit and push. The chart, running total and the commit counter on the page update from that file. The meta description in `index.html` and the CV PDF are static, so change those by hand.
